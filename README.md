# 5천만분의 1 — 대한민국 인생 & 건강보험 시뮬레이터

엄마 뱃속에서 임종까지 1년씩 살아 보며, 건강보험이 한 사람의 삶을 얼마나 받쳐 주는지 체험하는 웹 게임입니다.
일반 국민이 잘 모르는 건강보험의 혜택을, 공식 통계를 바탕으로 한 가상 인생을 통해 직접 느껴 보도록 만들었습니다.

## 접속 주소

**https://emerkdh-wq.github.io/hello-world-particle/**

- 설치 없이 휴대폰·PC 웹 브라우저로 바로 이용할 수 있습니다.
- 휴대폰 세로 화면에 맞춰 설계했습니다. PC에서는 화면 가운데에 휴대폰 폭으로 표시됩니다.

## 실행 방법

### 방법 1. 웹 주소로 실행 (권장)

1. 인터넷에 연결된 휴대폰 또는 PC에서 최신 브라우저(Chrome, Edge, Safari, 삼성 인터넷 등)를 엽니다.
2. 주소창에 **https://emerkdh-wq.github.io/hello-world-particle/** 를 입력합니다.
3. 「5천만분의 1」 제목과 「태어나기」 버튼이 보이면 정상 실행된 것입니다.

### 방법 2. 내려받아 PC에서 실행

1. https://github.com/emerkdh-wq/hello-world-particle 에서 **Code → Download ZIP**을 눌러 내려받습니다.
2. 압축을 풀고 폴더 안의 **`index.html`**을 더블클릭하면 브라우저에서 실행됩니다.
3. 아이콘과 글꼴을 인터넷에서 불러오므로 인터넷이 연결된 상태에서 실행하는 것을 권장합니다.

### 실행 환경

| 구분 | 내용 |
|---|---|
| 브라우저 | Chrome·Edge 111 이상, Safari 16.2 이상, Firefox 113 이상, 삼성 인터넷 22 이상 (Internet Explorer 미지원) |
| 필요 소프트웨어 | 없음 (웹 브라우저만 필요) |
| 네트워크 | 인터넷 연결 필요 (아이콘·글꼴·효과를 CDN에서 불러옴) |
| 저장 | 진행 상황은 저장되지 않음. 새로고침하면 새 인생으로 다시 시작 |

## 작동 방법

1. **시작:** 시작 화면의 「이 게임에 적용된 기준」에서 보험료율과 주요 통계를 확인하고 **「태어나기」**를 누릅니다. 이름과 성별은 무작위로 정해집니다.
2. **1년씩 진행:** **「1년 더 살기 (+1세)」**를 누르면 한 해가 지나고, 그해 진료일수·진료비·보험료 요약 카드가 맨 위에 나타납니다.
3. **소식 확인:** 그해 소식이 더 있으면 **「계속하기 · 새 소식 N개 더」** 버튼으로 하나씩 확인합니다.
4. **선택:** 진로, 직업, 결혼, 출산, 건강검진, 금연, 장기요양 등 선택지가 나오면 원하는 항목을 고릅니다. 선택지가 많으면 아래로 밀어 더 볼 수 있습니다.
5. **상태 확인:** 화면 위 상태창의 **ⓘ** 버튼으로 각 항목의 자세한 설명을 봅니다. 「접기」 버튼으로 상세 정보를 접을 수 있습니다.
6. **자동 진행:** **「자동」** 버튼을 누르면 선택지가 나올 때까지 자동으로 진행됩니다. 한 인생은 약 5~10분 걸립니다.
7. **엔딩:** 사망하면 일생 정리와 인생 영수증이 나타납니다. 「재정 이야기」, 「통계 출처」를 볼 수 있고, **「다시 태어나기」**로 새 인생을 시작합니다.

> 💡 흡연·음주를 하고 검진을 건너뛴 인생과, 금연·절주·운동·검진을 챙긴 인생을 차례로 해 보면 생활습관과 검진의 차이를 비교할 수 있습니다.
